# 2026年10月26日: ローカル分離モデルと操作の更新

## 追加した分離

| 目的 | モデル | 出力・注意 |
|---|---|---|
| 映像の3分離 | BandIt Plus / DBS-TIGER-DnR | DBSは44.1kHzモノラル。左右の定位は失われる |
| ボーカル・伴奏 | BS-RoFormer / MelBand RoFormer | 取り出したボーカルを元音源から差し引いて伴奏を作成 |
| 音楽6ステム | 上記ボーカルモデル → htdemucs_6s | 既存パイプラインの前段を選択可能 |
| 多楽器探索 | MVSep Mega 53 Stems v1 | 53カテゴリから必要な出力ヘッドだけを実行。カテゴリは重複する |

DBSの重みは約4.1MB。コードは公式コミット `ff526463a58ee0278e7bd05c4b8bce112b743e34`、重みはHugging Face revision `22da7d4cd3ea63f9365181008bff1c0d2ab6fb2b` を使用します。推論に不要なHub・学習用依存を外し、追加依存は `safetensors` のみです。CUDA版PyTorch 2.6.0+cu124は維持しました。

MegaはMSST公式リリース `v1.0.21` の設定と重みを使用します。選択ヘッドの順序と設定上の53カテゴリの対応をテストしています。公式推奨はVRAM16GB以上です。特定楽器の精度は専用モデルより低い場合があります。全出力の合計は原曲にならないため、エディタでは最初の出力だけを初期有効にします。

## 操作と保存

- モデル一覧に説明、取得済み・メモリ読込済み状態、ダウンロード容量、VRAM目安、公式配布元を表示。
- 任意の開始秒から5〜60秒を試し分離。動画もffmpegで同じ区間を抽出。末尾では実際に存在する区間だけを処理。
- 分離モデル切替時は前のモデルをCPUへ退避。メモリ解放ボタンは処理中に割り込まず、ディスク上の重みを保持。
- 同じタブで直近8件の処理を再表示。サーバー再起動でメモリ内ジョブ情報は消えるため、続きは `.ssproj` で保存。
- サーバー出力は32bit float WAV。ピークを固定で切り捨てず、分離時の細部を保持。
- バッチ用ZIPにモデル・品質・選択楽器・区間・チャンネル数を記録した `separation.json` を同梱。
- 編集後の書き出しも32bit floatを既定とし、16bit PCMを選択可能。プロジェクト内の音声は常にfloat保存し、ピークが1を超えたサンプルも再開時に保持。
- プレビューの保存名に開始秒のサフィックスを付加。編集後ZIPと `.ssproj` にもモデル・区間情報を保持。
- 不正なモデルとモードの組合せ、空の楽器指定、無効な区間、NaNを拒否。ダウンロード途中のファイルは `.partial` とし、成功時だけ公開。

モデル間の「精度何％」や異なるデータセットでのSDR順位は表示していません。素材ごとに短い区間で試し、音の混入・欠落とアタックを確認してください。

## SAM Audioなどの扱い

SAM Audioは文字・時間・映像による対象音抽出を行う公開技術ですが、公式重みのアクセス承認と認証が必要です。本更新ではアプリ内推論を追加していません。既存環境へ自動インストールも行っていません。利用する場合は別環境と連携する方式で検証する必要があります。

AV-CASSやMuS3Dも今回のアプリ内推論には含みません。実装済みとして選択肢には出しません。

## 検証

`.venv\Scripts\python.exe -m unittest discover -s tests -v` の25テストが成功。モデルとモードの検証、選択ヘッドの対応、足し戻し、モノラル維持、チャンク境界、区間抽出、サンプルレート変換、動的ステム配信、ZIP情報、処理中の解放拒否、ダウンロード中断・ハッシュ検証を確認しています。DBSのGPU試験はCUDAと取得済み重みがあるときに実行します。

ブラウザでは1280px/390pxの横はみ出し、モデル・楽器選択、区間入力、不正指定、履歴を確認。実DBSプレビューで5秒の4トラック（3出力＋元音源）を開き、カット・詰め削除・Undo、クライアントZIPのメタ情報、32bit floatの±1.25保持、`.ssproj` 保存・再開での音声・メタ情報の一致を確認しました。

RTX 4090では合成8秒音声を使い、BandIt・DBS・BS-RoFormer・MelBand・Megaの5モデルで出力長と有限値を確認。BS/Melのボーカル・伴奏は元音源への足し戻しも確認しました。既存の音楽6ステムも動作しています。Megaはアコースティックギターとピアノの2カテゴリを実推論し、どちらも入力と同じステレオ352,800サンプルを返しました。53カテゴリ同時出力や長尺素材の性能試験は実施していません。

最終API試験では、8秒音源の6秒地点から5秒を指定し、実際の残り2秒だけをMegaで分離。2つの出力が44.1kHz・ステレオ88,200サンプルになり、ZIPの `separation.json` に指定5秒と実尺2秒を区別して保持すること、モデル解放APIがキャッシュを解放することを確認しました。Megaの検証用重みは固定revisionのミラーから取得し、GitHub公式assetのSHA-256 `c62820893bbf86d4e734f966bd142d9157cfc8bb8e79e9d8f9ea553f3ff3519f` と一致を確認しました。アプリの初回ダウンロード先は公式リリースURLです。

合成音源による検証は、実装の正しさを確認するものです。実際の音楽・アニメ・ゲーム音声に対する聴感評価や正解ステム付きのSDR測定とは区別しています。
